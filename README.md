# calc-stage

Промежуточная (staging) версия калькулятора BitrixGPT для экспериментов.
Боевая версия — репозиторий `calc` (https://bitrixgpt.online).
Деплой сюда: `./deploy.sh --stage "коммит"`

`cowork.html` — стейджинг второго продукта, калькулятора Коворк/Код (боевая версия — репозиторий `cowork`, https://cowork.bitrixgpt.online). Собирается тем же `./deploy.sh --stage` из ядра канона BitrixGPT и шаблона `cowork.src.html`.
